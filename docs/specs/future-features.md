# 차기 기능 메모

v1 출시 후 검토할 아이디어 모음. 우선순위 낮음, 시간 여유 있을 때.

## 🐑 다마고찌/도트 스타일 정원

**아이디어**: 현재의 일러스트 톤 정원·홈을 도트(픽셀 아트)로 전환하거나 추가 모드로 제공.

**검토 포인트**:
- 적용 대상: ❌ 상점 단독보다 ✅ **정원/홈 전체에 적용**이 더 자연스러움
- 루양을 도트 캐릭터로 변환 → 먹이 주기, 잠재우기, 같이 묵상하기 등 다마고찌 메커닉
- 일종의 "클래식 모드" 토글 제공 (일러스트 ↔ 도트 전환)

**비용 추정**:
- 디자인 외주: 픽셀 아트 작가 의뢰 (루양 + 정원 자산)
- 개발: 1~2주 (애니메이션 시스템, 메커닉 구현)
- 기존 일러스트 자산과 톤 분리 — 사용자 선호 분기 가능

**선결 과제**:
- v1 출시 후 사용자 피드백 수집 → 도트 스타일 수요 확인
- 게임화 깊이가 어디까지 필요한지 사용자 인터뷰

## 🛒 상점 기능 (v1에서 일시 숨김)

**현재 상태**: 코드는 유지, UI 진입점만 차단 (home_screen 달란트 pill 비활성화).

**재활성화 방법** (5분):
1. `lib/features/home/screens/home_screen.dart`의 달란트 pill을 `GestureDetector(onTap: () => context.push('/store'), ...)` 로 복구
2. (선택) profile_screen에 store 진입 버튼 추가
3. AAB 재빌드

**개선 아이디어**:
- 달란트로 살 수 있는 아이템 종류 확장 (현재: 프레임/타이틀)
- 한정판 시즌 아이템 (이스터, 크리스마스 등)
- 도트/다마고찌 스타일 전환 시 함께 리뉴얼
